# 맵 회의 모드의 구성

회의 화면은 기존 오피스 캔버스와 실제 캐릭터를 재사용한다. 별도 회의 장면의 복제 캐릭터는
이동·좌석 정본과 분리되므로 회의 진입 경로에서 사용하지 않는다.

채널 조회·저장·서버 이동·브라우저 초기화는 같은 순수 맵 정규화를 소비한다. 조회는 저장 원본을
덮어쓰지 않고 유효 맵과 대표 회의 공간을 함께 반환한다. 정규화는 DB나 브라우저 객체에 의존하지 않는다.

상단 버튼 → 기존 경로 이동 → 도착 후 소켓 참가 → 서버 공간·좌석 검사 → 회의 패널과 카메라 집중 순서다.
화면 진입과 AI 토론 시작은 별개다. 토론 시작 요청은 선택 NPC 집결을 거쳐 기존 회의 실행기에 전달한다.
서버 공간 조정기는 예약·이동을 기존 NPC/플레이어 이동 계층에 위임하며 Hermes 호출 정책을 소유하지 않는다.

카메라는 실제 액터 스냅샷과 회의 공간만 소비한다. 사람은 사용자 ID, NPC는 NPC ID로 발언자와 연결한다.
카메라 회전·자동 연출 설정은 브라우저 개인 상태이며 서버나 다른 참가자에게 전파하지 않는다.
회의 내용·공간 상태는 회의 참가 룸에, 일반 사용자에게 필요한 이동·좌석 프레즌스만 맵 룸에 전달한다.
