# 맵 회의 규칙

- 대표 회의실은 채널당 하나다. 명확한 기존 회의 공간을 우선하며, 탁자 이름만으로 라운지를 전환하지 않는다.
- 회의실이 없거나 후보가 불명확하면 가장자리에 연결 통로와 회의실을 증축한다. 기존 배치·ID·스폰 좌표는 유지하고
  연결에 필요한 경계 출입구만 연다. 안전한 통로를 만들 수 없으면 오류이며 순간이동이나 별도 장면으로 대체하지 않는다.
- 상단 회의실 버튼은 도보 이동을 시작한다. 도착해야 참가하며, 이동 취소·다른 이동 명령은 진입 의도를 취소한다.
  회의실 안에서는 준비 화면을 바로 열 수 있다. 입장 자체로 AI를 호출하지 않는다.
- 빈 실제 좌석을 우선하고 초과 인원은 안전한 빈 위치에 선다. 점유자를 밀어내지 않으며 공간까지 부족하면 대기·재시도를 표시한다.
- NPC 선택은 미리보기다. 주제와 시작 요청이 있어야 호출하며, 선택 NPC가 모두 도착한 뒤 토론을 시작한다.
  도착 실패를 조용히 제외하지 않는다. 선택 수정·재시도 또는 준비 취소로 해결한다.
- 개인 퇴장은 본인 참여와 임시 예약만 해제한다. 전체 종료·준비 취소는 호출 NPC의 원래 위치 복귀를 수행한다.
  원래 자리가 점유되었으면 가까운 안전 위치로 돌아가며 업무용 자리 지정은 바꾸지 않는다.
- 회의 중 사용자 줌·팬·이동·좌석 변경은 잠근다. 회전은 가능하고 직접 회전하면 자동 연출을 중단한다.
  자동 카메라 버튼으로만 재개한다. 실제 발언의 자동 확대는 사용자 줌 잠금과 별개다.
- 생각 중·작업 중 상태는 발언이 아니다. 실제 발언 시작·교체에만 카메라를 연출하며 스트림 글자마다 재시작하지 않는다.
- 벽 투명화는 시각 효과다. 충돌·좌석에는 영향을 주지 않으며 나가기·맵 변경·해제 시 원래 재질을 복원한다.
