# 실제 맵 회의실과 개인 카메라

## 맥락

별도 회의 장면은 맵의 회의실·캐릭터·좌석과 떨어져 있어 입장과 실제 이동이 연결되지 않았다.
기존 사용자 맵에는 회의실이 없거나 속성이 불명확한 경우도 있다.

## 결정

같은 맵의 대표 회의실을 사용하고 상단 버튼은 걸어서 도착한 뒤 화면을 전환한다.
분명한 회의실이 없으면 가장자리에 연결된 공간을 증축한다. 사용자가 직접 회전하면 자동 연출을 멈추고,
자동 카메라 버튼으로 재개한다. 수동 줌은 잠그되 발언자의 자동 확대는 허용한다.

## 대안과 결과

- 순간이동은 빠르지만 실제 공간에서 모이는 경험을 끊으므로 선택하지 않았다. 경로 실패를 성공처럼 숨길 수 없다.
- 기존 맵의 빈 공간에 삽입하면 지도가 작아지지만 사용자 배치와 통로를 침범할 수 있어 가장자리 증축을 선택했다.
  맵 크기는 늘어나며 기존 좌표·ID는 유지해야 한다. 반복 적용으로 증축이 누적되어서는 안 된다.
- 사용자의 회전 뒤 자동 연출을 즉시 재개하면 의도한 시야를 빼앗으므로 명시적 재개를 택했다.
  카메라 상태는 참가자마다 독립이며 다른 사람과 같은 각도를 강제하지 않는다.
- 증축의 충돌용 내부 채움 벽을 지우면 이동 가능 영역까지 달라지므로, 생성 표식에 따른 표시만 생략한다.
  표식이 없는 기존 벽은 추측으로 숨길 수 없다.
