# 임원 오피스 레퍼런스 구현

사용자 제공 `임원 오피스.png`를 기준으로 한다. 독립된 한 방 안에 좌측 업무석,
우측 후면 6인 회의석, 우측 전면 응접석을 배치한다. 일반 사무실의 세 방 구조는 사용하지 않는다.

## 구현 계약

- executive v3는 18×18, 입구는 중앙 3칸, 시작점은 (9,15).
- 월넛 벽·책장·책상, 황동 프레임·벽등, 크림 소파·브라운 안락의자,
  베이지 석재 바닥과 직물 러그를 사용한다.
- 후면은 창과 중앙 서가, 전면은 낮은 투명 유리와 연결된 프레임이다.
- 벽은 카메라에 따라 숨기지 않는다. 실루엣과 이음새가 회전해도 유지되어야 한다.
- 배치는 executive-room-layout, 외피는 executive-architecture, 공용 가구는
  room-furniture로 분리한다. 런타임 이동·좌석 소유권은 기존 공용 로직을 따른다.
- 대표 업무 구역은 ambientZones로 산책에서 제외한다. 회의·라운지는 허용한다.
- 신규 맵 생성 시 크기에서 시작점을 계산한다. 기존 채널 DB를 배포만으로 덮어쓰지 않는다.

## 변경 시 확인

- 입구에서 모든 좌석 앵커까지 왕복 경로가 있고 가구 footprint가 겹치지 않는가?
- 가구의 실제 형상은 등록된 충돌 범위 안에 있는가?
- 착석 높이와 의자 중심은 공용 resolveSeat/sofaSeats와 일치하는가?
- 전면 프레임 끝·코너에 틈이나 돌출이 없는가?
- 목재·금속·직물에 서로 다른 roughness와 질감을 사용했는가?
- 투명 유리는 depthWrite를 끄고 겹치는 면을 만들지 않았는가?
- 그림자·창·소품은 사용자/NPC 이동을 잘못 막지 않는가?
- 다른 네 환경의 배치·재질·입구에 회귀가 없는가?

## 시각적 한계

실시간 스타일화 미니어처 구현이다. 레퍼런스 사진의 광택 대리석 반사와
실사 도시 파노라마를 그대로 재현하지 않으며, 현재 도시 배경은 절차적 실루엣이다.
회의 테이블은 기존 4×2 좌석 계약에 맞춘 타원형이다.

## 업무석 PBR 에셋 1차 (2026-09-14)

- 책상·대표 의자·후면 책장·업무석 러그를 독립 GLB로 제작했다.
- 월넛/가죽/직물은 1024px 색상·노멀·거칠기 텍스처를 포함한다. 사진 스캔이 아닌
  자체 생성한 절차적 텍스처이며, 황동은 별도 금속 재질이다.
- 모서리 bevel, 의자 쿠션/봉제선/캐스터, 서랍 틈/손잡이, 책/도자기/식물,
  데스크 램프와 가죽 패드를 형상으로 넣었다.
- 제작 원본은 `scripts/assets/build-executive-furniture.py`, 산출물은
  `public/assets/furniture/executive/`다. Blender 5.1.1에서 다음으로 재생성한다:
  `blender --background --factory-startup --python-exit-code 1 --python scripts/assets/build-executive-furniture.py`
- 텍스처는 WebP로 GLB에 내장한다. 4종 합계 약 5MB, 제작 통계는 build-report.json.
- 로딩 실패 시 기존 가구를 유지한다. 맵 해제 후 도착하는 모델도 폐기하며,
  비동기 가구는 정적 배칭에서 제외해 중복 표시를 막는다.
- 좌석 앵커/충돌/공간 정책은 기존 모듈이 계속 소유한다. 의자의 좌판 중심 높이는
  0.47m, 상단은 0.54m이며 새 모델을 위해 저장된 좌석 좌표를 바꾸지 않는다.
- 이번 범위는 업무석이다. 회의석·응접석·벽/바닥·도시 배경은 아직 같은 수준의
  에셋으로 교체되지 않았다. 전체 레퍼런스 품질 달성으로 간주하지 않는다.

## 회의석·응접석·외피 PBR 2차 (2026-09-14)

- 회의 테이블, 방문/회의 의자, 2인 소파, 1인 안락의자, 응접 테이블을 추가했다.
- 소파는 기존 2개 좌석 중심(±0.38), 앞쪽 이동량(+0.3), 몸체 전면(+0.4)을 유지한다.
  쿠션 좌판 상단은 약 0.53m다. 좌석 수·방향·저장 좌표는 변경하지 않는다.
- 크림 직물, 코냑 가죽, 월넛, 석재를 구분하고 쿠션 파이핑·책·매트·식물을 추가했다.
- 벽과 바닥은 가구의 월넛/석재와 같은 색상·노멀·거칠기 텍스처를 사용한다.
  황동 세로줄 대신 어두운 패널 줄눈과 상하 황동 마감을 넣었다.
- 건축 재질은 비동기 로딩 후에도 동일 재질 객체를 유지하도록 배칭한다.
  맵 해제 후 도착하는 텍스처는 폐기한다. 일반 맵의 배칭 방식은 유지한다.
- 이 단계 이후에도 도시 배경·대형 식재·조명 연출의 레퍼런스 수준 개선은 남는다.
  사진과 동등한 완성도로 간주하지 않는다.

## 공유 조경·도시 배경 3차 (2026-09-14)

- 공유 카탈로그 `src/game/three/shared-scene-assets.ts`에 유리/석재 타워,
  가로수, 광엽/세엽 실내 화분 5종을 등록했다. 에셋은 `/assets/shared/landscape/`.
- 다른 맵에서 같은 ID와 `attachSceneAsset`으로 재사용한다. 현재 적용은 임원실이며,
  실내 화분은 기존 1×1 타일 충돌 범위를 유지한다.
- 잎은 곡면·끝·중앙 잎맥이 있는 개별 면이고 가지는 끝으로 가늘어진다.
  화분에는 실제 테두리와 내부 흙, 빌딩에는 개별 창호·입면·옥상 설비가 있다.
- 외부 에셋은 이동 장애물로 등록하지 않는다. 건물은 두 깊이로 배치하며 실내로
  과대한 그림자를 드리우지 않는다. 가로수는 회전·축척을 달리해 반복을 완화한다.
- 제작 원본 `scripts/assets/build-shared-landscape.py`; 자체 제작, 외부 에셋 미사용.
  개별 모델 2MB·6만 삼각형 상한과 카탈로그 크기를 테스트로 고정한다.
- 실사 사진 합성이나 사진 스캔 에셋이 아니며, 실시간 미니어처용 상세 형상이다.
