# 임원 오피스 레퍼런스 구현

사용자 제공 `임원 오피스.png`를 기준으로 한다. 독립된 한 방 안에 좌측 업무석,
우측 후면 6인 회의석, 우측 전면 응접석을 배치한다. 일반 사무실의 세 방 구조는 사용하지 않는다.

## 구현 계약

- executive v3는 18×18, 입구는 중앙 3칸, 시작점은 (9,15).
- 월넛 벽·책장·책상, 황동 프레임·벽등, 크림 소파·브라운 안락의자,
  베이지 석재 바닥과 직물 러그를 사용한다.
- 후면은 창과 중앙 서가, 전면은 낮은 투명 유리와 연결된 프레임이다.
- 벽은 카메라에 따라 숨기지 않는다. 실루엣과 이음새가 회전해도 유지되어야 한다.
- 배치는 executive-room-layout, 외피는 executive-architecture, 공용 가구는
  room-furniture로 분리한다. 런타임 이동·좌석 소유권은 기존 공용 로직을 따른다.
- 대표 업무 구역은 ambientZones로 산책에서 제외한다. 회의·라운지는 허용한다.
- 신규 맵 생성 시 크기에서 시작점을 계산한다. 기존 채널 DB를 배포만으로 덮어쓰지 않는다.

## 변경 시 확인

- 입구에서 모든 좌석 앵커까지 왕복 경로가 있고 가구 footprint가 겹치지 않는가?
- 가구의 실제 형상은 등록된 충돌 범위 안에 있는가?
- 착석 높이와 의자 중심은 공용 resolveSeat/sofaSeats와 일치하는가?
- 전면 프레임 끝·코너에 틈이나 돌출이 없는가?
- 목재·금속·직물에 서로 다른 roughness와 질감을 사용했는가?
- 투명 유리는 depthWrite를 끄고 겹치는 면을 만들지 않았는가?
- 그림자·창·소품은 사용자/NPC 이동을 잘못 막지 않는가?
- 다른 네 환경의 배치·재질·입구에 회귀가 없는가?

## 시각적 한계

실시간 스타일화 미니어처 구현이다. 레퍼런스 사진의 광택 대리석 반사와
실사 도시 파노라마를 그대로 재현하지 않으며, 현재 도시 배경은 절차적 실루엣이다.
회의 테이블은 기존 4×2 좌석 계약에 맞춘 타원형이다.
