# 회의 모드 엔지니어링 노트

- npm 전역 설치본은 `node_modules/deskrpg/src`에 놓인다. `tsx`의 tsconfig 경로 별칭은 그 위치에 적용되지
  않아 공개 `2026.9.18`·`2026.9.19`의 `deskrpg start`가 첫 `@/db`에서 죽었다. 소스/도커 기동만으로
  npm 경로를 검증했다고 보지 말고, 레지스트리 설치본을 격리 prefix의 `node_modules`에 두어
  `init`→`start`→`/auth`까지 확인한다. 새 런타임 파일은 npm `files`와 Dockerfile COPY 양쪽에 포함한다.
- master CI의 GHCR `sha-<full-SHA>` 푸시는 운영 후보 게시일 뿐 자동 운영 전환이 아니다. CI 전체 초록
  확인 후 digest로 고정한다. 날짜 태그 공개 릴리스는 amd64/arm64 네이티브 러너에서 별도 빌드하고
  매니페스트를 묶는다. 첫 GHCR 공개 태그가 익명 pull 가능해지기 전에는 기존 Compose 기본 이미지를
  존재하지 않는 GHCR `:latest`로 바꾸지 않는다.

- 좌석에 도착했는데 준비 상태가 계속 walking이면 도착 거리부터 늘리지 않는다. 늦은 일반 `seat:claim`이
  회의 예약을 일반 예약으로 교체하면 공간 도착 콜백이 사라진다. 같은 소유자의 같은 회의 좌석 재요청은 예약을
  유지한 성공으로 처리하고 일반 변경·해제는 거절한다. 실제 move→arrival 콜백과 개인 퇴장 예약 해제를 함께 검증한다.
- NPC 복귀 도착 뒤에도 `spatial` 예약 표식이 남으면 일반 좌석 변경이 `meeting_reserved`로 막힌다.
  도착·세대 검증을 마친 뒤 업무 위치에서는 일반 귀가처럼 예약과 원정 슬롯을 해제하고, 다른 실제 좌석에서는
  일반 도착 예약으로 전환한다. 복귀 중 보호, 물리 점유, 원정 수 제한과 이동 담당자 교체 후 좌석 변경도 함께 검증한다.
- 가구 텍스처가 늦게 도착하면 mapKey가 바뀌어 맵을 다시 그린다. 이를 실제 맵 변경으로 취급하면 회의 카메라가 풀린다.
  구조가 같으면 카메라는 유지하고 벽 참조만 재등록한다. 진짜 기하 변경에서는 기존 카메라·재질을 복원한다.
- Tiled 증축 바닥에 1을 하드코딩하면 빈 tilesets 또는 firstgid가 100인 유효 맵에서도 Phaser 로딩이 죽는다.
  정의가 확인된 기존 바닥 GID를 재사용하고 없으면 0을 쓴다. 뒤집기 비트는 유효성 판정 때만 제거한다.
  합성 테스트 맵도 tilesets가 비어 있으면 바닥 0을 사용한다.
- 회의실 근처 벽만 가림 후보로 등록하면 낮은 각도에서 외벽이 참가자를 가린다. 실제 건축 빌더의 외벽·유리·창틀도
  등록하고 개별 재질 복원이 가능하도록 배칭에서 제외한다. 바닥·가구·도시 배경까지 등록하면 안 된다.
- 증축의 미사용 셀을 막는 객체를 모두 그리면 수백 개 평행 파티션이 생긴다. 충돌 객체를 삭제하지 말고 생성 ID가
  명시된 벽의 렌더링만 경계와 코너로 제한한다. 저장·재정규화 후 ID/좌표 불일치는 표식을 무시하는 쪽으로 복구한다.
- 브라우저 검증에서 캔버스 존재만 기다리면 스폰 전에 클릭할 수 있다. player:spawn·players:state·npc:motion-state와
  실제 프레임 진행을 기다린다. 소켓 프레임의 ack 숫자가 붙은 `42<id>[...]`도 관찰 파서에서 처리한다.
- 최신 공식 trading 맵의 대표 회의실은 `conference` 영역이다. 일반 사용자 맵의 라운지 이름까지 추론 범위를
  넓히지 말고 공식 버전에서만 인식한다. agency v3+는 API 정규화에서도 맵 스폰이 정본이며 오래된 설정 스폰을
  사용하면 서버 이동 투영과 API가 서로 달라질 수 있다.
- 비동기 건축 최종화는 `dynamicAsset` 표식을 지운다. 회의 벽은 영구 `meetingWall` 표식으로 외부 배칭에서
  제외하고 같은 벽면 내부만 배칭한다. 실제 GLTF 스튜디오 건축은 33 draw calls로 기존 35 미만 예산을 유지한다.
  임시 투명 재질은 `meetingOcclusion` 표식으로 배칭에서 제외하며, 자산 완료 뒤 활성 회의의 벽 후보를 다시 등록한다.
- 일반 템플릿 크기 제한은 40×30을 유지한다. 넓은 공식 맵은 전체 스냅샷 일치 예외로만 허용하며, 회의실 증축은
  채널 맵 정규화 단계에서 처리한다. 증축 때문에 일반 템플릿 제한을 넓히지 않는다.
- 맵 갱신은 motion 예약뿐 아니라 회의 공간 세션·준비 대기·작업 큐·참가자 연결·브로커·회의 소켓 구독까지
  폐기한다. 세대 워터마크는 유지해 이전 도착 패킷이 새 회의에 적용되지 않도록 한다.
- 권위 위치나 홈 변경으로 NPC 경로를 취소하면 `spatialNpcRoutes`도 무효화한다. 세대 번호가 같다는 이유로
  취소된 경로의 재시작을 건너뛰면 회의 집결이 멈춘다. 액터 제거 때도 해당 경로 캐시를 지운다.
- 벽 가림 시선은 서버 충돌 좌표가 아니라 렌더링에 쓰는 `seatAt`의 착석 보정 위치를 사용한다. 스튜디오 좌석은
  표시 위치가 약 0.85m 다를 수 있어 낮은 모서리 시점에서 다른 벽을 투명화하게 된다. 실제 GLTF와 카메라 좌표로
  흰 외벽을 관통하는 시선 회귀를 확인한다.
- 게시판 이동 예약은 회의실 도착뿐 아니라 도보 진입 시작 때 취소한다. 회의 진입 중 새 게시판 명령도 막아
  회의실로 이동하다 칸반 모달이 열리지 않게 한다. 좌석 호버·선택 유지는 하나의 가구 강조 렌더러를 공유한다.
